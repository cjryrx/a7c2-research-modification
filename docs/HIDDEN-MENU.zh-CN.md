# 查看被隐藏的设置（运行期补丁）

相机固件把一批自定义键功能"藏"了起来：条目和标签都在资源里，但可选性校验函数
`is_valid_custom_key_setting_select_function_item`（vaddr `0x1B6E1C4`）读到的标志字节是 0，
所以列表里不显示。

把该函数改成"永远返回真"，列表就会把这些条目也画出来。**只改运行中的内存，不动固件，关机即恢复。**

## 前提

* 相机开机，停在**拍摄界面**（不要停在菜单里；补丁打在菜单打开状态上会让 app 崩溃重启）；
* 相机已用 USB 连上电脑，且没有别的程序占用（不要同时开 Imaging Edge / 别的工具）；
* app 已完全启动（开机后等 30 秒左右）。

## 一条命令

```bat
py tools\apply_hidden_menu.py
```

工具会自动做这些事：

1. 读 `/proc/<pid>/maps`，找到 appFw 的 `.text` 映射（约 85 MiB，`/usr/lib/appFw.so`）；
2. 按已知的两个候选 `.text` 偏移 + 若干构建偏移，逐个读 8 字节，
   **只有读到 `stp x29,x30,[sp,#-0x40]! ; mov x29,sp` 才认为是校验函数**；
3. 现场生成一个 224 字节的静态 AArch64 小程序（`openat` + `pwrite64`，无 libc）——
   因为机身 busybox 的 `dd` 只能处理 32 位偏移，直接写 `0x7f...` 会报 `File too large`；
4. 把它写到相机 `/tmp/jiritsu/poke.bin`，执行，把校验函数首两条指令改成
   `mov w0,#1 ; ret`（`20 00 80 52 C0 03 5F D6`）；
5. 读回 8 字节确认。

## 然后

打开 **MENU → 拍摄 → 自定义键/拨盘设置 → 自定义键(拍摄)** → 点进某个键的功能列表，
就能看到原本隐藏的条目（包括两个"连拍速度提升"）。

**注意**：选中"连拍速度提升"会让 app 崩溃、机身自动重启——它的执行路径在这台机身上不存在。

## 恢复

```bat
py tools\apply_hidden_menu.py --revert
```

或者直接关机再开机（内存补丁本来就只在本次开机有效）。

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `validator not found` | app 还没加载完，或相机不在拍摄界面。加 `--wait 180` 让它自动重试 |
| `GenericUsbException` / 超时 | 相机的服务线程卡了。等 20–30 秒重试；仍不行就断电重启 |
| 打完补丁后相机立刻重启 | 补丁是在菜单/列表已打开时打的。回到拍摄界面等待，再执行一次 |
| 菜单里条目很多但都点不动 | 正常，很多隐藏项在这台机身上没有实现 |
